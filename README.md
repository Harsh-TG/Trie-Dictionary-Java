# Trie-Dictionary-Java

### Approach

Hello sir/ Mam, Initiall, I am try to solve the problem using a simple array/list to store all the words. In that approach, whenever I needed to search for a word or find suggestions based on a prefix, I had to check every word in the array. This worked for small data, but it was not efficient because the program that i am write had to scan the entire list each time.

After realizing this limitation, I decided to use a Trie data structure. 

In my implementation:

Step 1: Add Word
Then step 2: Search Word
Then step 3: Suggest Words 
and last display

Using Trie improves performance because searching and prefix operations depend mainly on the length of the word, rather than the total number of words stored.
